## Why two licences · Por qué dos licencias

**EN.** This repository is a single HTML file that contains both a program and a body of
editorial work. Creative Commons licences are not intended for software, and permissive
software licences say nothing useful about attribution of texts. So each part carries the
licence it was designed for.

**ES.** Este repositorio es un archivo HTML único que contiene a la vez un programa y un
cuerpo de trabajo editorial. Las licencias Creative Commons no están pensadas para
software, y las licencias permisivas de software no dicen nada útil sobre la atribución
de textos. Por eso cada parte lleva la licencia que le corresponde.

## Where the boundary runs · Dónde está el límite

Under **MIT** ([LICENSE](LICENSE)) / Bajo **MIT**:

- the HTML structure, the CSS and all the JavaScript;
- the layout and measurement engine, the SVG generator, the QR guards and the test suite.

Under **CC BY 4.0** (this file) / Bajo **CC BY 4.0**:

- the **notation**: the two-letter codes, the `AI: ` prefix, the `+` separator, the
  level-of-use scale and the composition rules;
- the **texts**: interface strings, user guide, "About", the prose declaration templates
  and the Spanish and Portuguese renderings of the activity descriptions;
- the **label design**: proportions, typographic hierarchy and composition;
- the **brand icon**.

In practice: if you reuse the machinery, MIT applies. If you reuse the notation, the
wording or the visual design — including adopting the label in a journal — CC BY 4.0
applies, and attribution is required.
